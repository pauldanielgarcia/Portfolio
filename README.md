# Paul Garcia — Video Editor Portfolio

A responsive, dark-cinematic portfolio website with electric-blue accents. Built with plain HTML, CSS, and JavaScript so it can be hosted for free with GitHub Pages.

## Preview locally

1. Download or clone this repository.
2. Open `index.html` in your browser.

No build tools or dependencies are required.

## Before publishing — personalize these details

### 1. Add your real work

Open `script.js` and replace the four sample project entries in the `projects` array:

- `title`: your real project title
- `category`: the project type
- `videoUrl`: a public YouTube, Vimeo, or direct video URL
- `message`: optional preview note

Also update the project titles and descriptions in `index.html` so they match your work. The current project covers are design placeholders, not actual client work.

### 2. Update your contact links

In `index.html`, replace:

- `hello@paulgarcia.com` with your professional email
- The email button's `mailto:` address
- Add your actual Instagram, LinkedIn, or other professional profile links in the footer if you want them shown.

### 3. Update your bio and services

Edit the About and Services sections in `index.html` to accurately reflect your experience, editing tools, specialties, and the services you offer.

## Publish with GitHub Pages

1. Sign in to GitHub and create a new **public** repository, for example `paul-garcia-portfolio`.
2. Upload the contents of this folder to the repository root. Make sure `index.html`, `styles.css`, and `script.js` are at the top level.
3. Open the repository's **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
6. Wait for GitHub Pages to publish. Your website will be available at `https://YOUR-GITHUB-USERNAME.github.io/paul-garcia-portfolio/`.

If you name the repository `YOUR-GITHUB-USERNAME.github.io`, the site can instead use the shorter root URL `https://YOUR-GITHUB-USERNAME.github.io/`.

## Notes

- The site is mobile responsive.
- Project filters work without a backend.
- Project preview cards are placeholders until you add your own video URLs.
- The email contact button must be updated before sharing the portfolio with clients.
- Google Fonts are loaded from Google Fonts; a system sans-serif fallback is provided.
