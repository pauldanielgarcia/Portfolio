HOW TO UPDATE GITHUB
1. Extract this ZIP on your computer.
2. Open your existing GitHub repository folder (or clone it with GitHub Desktop).
3. Replace index.html with this updated index.html.
4. Copy the entire videos folder into the repository, keeping it beside index.html.
5. Your email, WhatsApp, and Instagram links are already added to the Contact section.
6. Commit and push the changes. GitHub Pages will redeploy.
